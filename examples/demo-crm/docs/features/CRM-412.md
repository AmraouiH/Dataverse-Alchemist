# CRM-412 - Manage equipment covered by a service contract

<!-- alchemist:auto:start -->
> Ticket: CRM-412 · Type: Story · Status: Done · Date: 2026-11-12

## Need

Nous voulons suivre les équipements installés chez nos clients et couverts par un contrat de service.

Créer une table Équipement avec : le nom, un numéro de série unique, le type d'équipement (Climatisation, Chauffage, Électricité, Plomberie), la date de mise en service, la date de fin de garantie, le compte client et le contrat de service. Un indicateur « Sous garantie » doit se calculer tout seul à partir de la date de fin de garantie.

Il faut un formulaire, une vue des équipements sous garantie, l'accès depuis l'application Service Client (groupe Contrats) et les droits pour le rôle Gestionnaire de contrats (lecture, création, écriture). Aucune documentation n'existe : l'initier.
