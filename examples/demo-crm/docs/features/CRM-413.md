# CRM-413 - Track interventions on equipment

<!-- alchemist:auto:start -->
> Ticket: CRM-413 · Type: Story · Status: Done · Date: 2026-11-12

## Need

Les techniciens interviennent sur les équipements. Créer une table Intervention : équipement, date d'intervention, statut (Planifiée, Réalisée, Annulée ; Planifiée par défaut), durée en heures, technicien (utilisateur) et compte rendu.

Règles :
- quand une intervention passe à Réalisée, la date de dernière intervention de l'équipement est mise à jour avec la date de l'intervention (nouvelle colonne sur l'équipement), sans jamais reculer ;
- le compte rendu est obligatoire dès que l'intervention est Réalisée ;
- une intervention Réalisée doit avoir une durée positive, sinon l'enregistrement est refusé avec un message clair.
